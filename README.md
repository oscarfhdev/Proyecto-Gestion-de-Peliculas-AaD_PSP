# 🎬 Proyecto de Gestión de Películas

## 📖 Descripción General

Este proyecto es una aplicación completa de **gestión de películas**, desarrollada como trabajo integrador de las asignaturas:

- **Programación de Servicios y Procesos**
- **Acceso a Datos**
- **Desarrollo de Interfaces**

El objetivo es aplicar de forma práctica los conceptos de **hilos y procesos**, **arquitectura cliente-servidor** y **buenas prácticas de desarrollo full-stack**, utilizando **Spring Boot** en el backend y **React** en el frontend.

---

## 🧩 Tecnologías Principales

### 🖥️ Backend (Spring Boot)
- **Spring Boot 3+**
- **Spring Data JPA / Hibernate**
- **Spring Web (RESTful API)**
- **PostgreSQL Docker** 
- **Manejo de hilos y procesos** (ExecutorService, CompletableFuture, etc.)
- **Maven** 

### 💻 Frontend (React)
- **React**
